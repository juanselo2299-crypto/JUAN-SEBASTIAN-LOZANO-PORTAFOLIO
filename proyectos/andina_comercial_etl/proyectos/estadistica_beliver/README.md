#  Análisis Estadístico y Proyección de Ventas - Barbería Beliver

##  Resumen del Proyecto
Análisis estadístico cuantitativo descriptivo realizado para la Barbería Beliver en Medellín. El objetivo principal fue analizar los ingresos mensuales y establecer una proyección confiable para el mes de diciembre utilizando estadística básica y regresión lineal.

##  Hallazgos Clave
*   **Probabilidad:** 80% de los clientes eligen un servicio que incluye corte (corte sencillo o corte y barba).
*   **Proyección:** Mediante regresión lineal, se estimó un incremento del 30% en la demanda para temporada alta, pasando de 408 a 530 servicios mensuales.
*   **Rentabilidad:** Cada servicio aporta en promedio 31.000 COP al ingreso total.
